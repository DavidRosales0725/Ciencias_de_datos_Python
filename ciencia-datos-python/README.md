# Ciencia de Datos con Python - Semana 1

## Propósito
Preparar el ambiente de trabajo reproducible y comprender la transformación del dato en decisiones dentro del contexto del SENA y el desarrollo de software.

## Estructura del Repositorio
- `data/raw`: Datos originales intactos.
- `data/processed`: Datos limpios y transformados.
- `notebooks`: Cuadernos de análisis interactivos (Jupyter).
- `outputs`: Reportes, gráficos y exports.
- `docs`: Documentación técnica y guías.
- `scripts`: Código Python ejecutable y reutilizable.

## Buenas Prácticas
1. **Inmutabilidad:** No modificar directamente los datos de `data/raw`.
2. **Privacidad:** Garantizar el anonimato de datos sensibles.
3. **Rutas:** Trabajar siempre con rutas relativas (`Pathlib`).
4. **Reproducibilidad:** Mantener `requirements.txt` actualizado.
